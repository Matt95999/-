GPT-5.4 系列将于 8 月 31 日从 Codex 中退役

OpenAI 宣布，自 2026 年 8 月 31 日起，GPT-5.4 和 GPT-5.4 mini 将不再在 Codex 中供使用 ChatGPT 登录的用户使用。

这两个模型仍将在 OpenAI API 上继续可用，但 Codex 用户需要迁移到其他模型。

这一变化可能促使 Codex 用户转向更新的模型，如 GPT-5.6 系列。

结论：这是 Codex 产品线的一次模型迭代，旨在推动用户采用更新模型。

影响：开发者需要调整 Codex 中的模型选择，可能影响依赖 GPT-5.4 的自动化工作流。

https://developers.openai.com/codex/changelog/#gpt-5-4-and-gpt-5-4-mini-retire-from-codex-on-august-31

Codex 更新：浏览器升级、多仓库审查和图像编辑

最新 ChatGPT 桌面应用更新使浏览、代码审查和生成图像编辑更快更易用。

内置浏览器提供更快的上下文查找，支持多仓库代码审查，并增强了图像编辑功能。

这些功能旨在提升开发者在 Codex 中的整体效率。

结论：这是 Codex 产品体验的持续优化，强化其作为开发助手的实用性。

Codex CLI 0.146.0 发布

Codex CLI 0.146.0 通过 npm 发布，新增功能包括使用 /new 或 /clear 命名新会话、固定重要线程等。

这些更新持续改进命令行工具的用户体验和稳定性。
