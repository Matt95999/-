## 按产品线出块

### Codex

本期 Codex 入选 2 条高置信线索，主线集中在 GPT-5.4 系列从 Codex 退役以及桌面应用功能升级。

#### GPT-5.4 系列将于 8 月 31 日从 Codex 中退役

- OpenAI 在 Codex 开发者更新日志中宣布，自 2026 年 8 月 31 日起，GPT-5.4 和 GPT-5.4 mini 将不再对使用 ChatGPT 账号登录的 Codex 用户开放。
- 不过，这两个模型仍可通过 OpenAI API 继续使用，开发者可不受影响地调用。
- 这一调整意味着 Codex 产品将逐步迁移到更新的模型版本，用户需要适应新的模型选择。
- 结论：这是 OpenAI 对 Codex 产品线进行模型版本迭代的正常退役安排，属于预期内的产品生命周期管理。
- 影响：对 Codex 用户而言，需要提前规划模型切换，避免在截止日期后因模型不可用而中断工作流；对开发者而言，API 通道不受影响，但需关注后续替代模型的性能表现。
- 原文：https://developers.openai.com/codex/changelog/#gpt-5-4-and-gpt-5-4-mini-retire-from-codex-on-august-31

#### Codex 桌面应用更新：浏览器升级、多仓库审查与图像编辑

- OpenAI 发布了 ChatGPT 桌面应用的最新更新，版本号为 26.727，主要改进了内置浏览器的使用体验，使用户能更快地浏览和查找上下文。
- 新版本还支持多仓库代码审查，并增强了生成图像的编辑功能，使相关操作更快捷。
- 这些功能更新旨在提升开发者在 Codex 中的日常工作效率。
- 结论：这是 Codex 产品体验的常规迭代，重点强化了浏览器、代码审查和图像编辑三大场景。
- 影响：开发者将获得更流畅的交互体验，多仓库审查功能尤其有利于大型项目协作，可能提升 Codex 在开发工具市场的竞争力。
- 原文：https://developers.openai.com/codex/changelog/#browser-upgrades-multi-repository-review-and-image-editing-26-727

### DeepSeek

本期 DeepSeek 入选 1 条高置信线索，重点在于 DeepSeek-V4-Flash 模型 API 公开测试版发布。

#### DeepSeek-V4-Flash API 公开测试版发布

- DeepSeek 官方 API 文档更新显示，DeepSeek-V4-Flash 的 API 已进入公开测试阶段。
- 调用方式保持不变，开发者只需将模型名称设置为 deepseek-v4-flash 即可使用最新模型。
- 该更新发布于 2026 年 7 月 31 日，属于模型迭代的重要节点。
- 结论：DeepSeek-V4-Flash 的公开测试标志着 DeepSeek 在模型推理速度和产品化上迈出关键一步。
- 影响：开发者可以立即通过 API 体验新模型，测试其性能与稳定性，为后续生产环境集成做准备；同时可能加剧与 OpenAI、Anthropic 等厂商的竞争。
- 原文：https://api-docs.deepseek.com/updates#deepseek-v4-flash-update

### Mistral

本期 Mistral 入选 1 条高置信线索，重点在于推出开源多模态安全分类器 Shieldstral。

#### Mistral 推出开源多模态安全分类器 Shieldstral

- Mistral 于 2026 年 8 月 4 日发布新闻，宣布推出 Shieldstral，一个拥有 30 亿参数的开源多模态安全分类器。
- 该模型声称在安全分类性能上优于体积高达其 7 倍的模型。
- Shieldstral 的发布旨在为多模态人工智能应用提供更高效的安全检测方案。
- 结论：Shieldstral 是 Mistral 在人工智能安全领域的重要布局，以轻量级模型实现高性能安全分类。
- 影响：开源发布将吸引开发者和企业采用，可能推动多模态安全检测的标准化，同时增强 Mistral 在安全工具市场的存在感。
- 原文：https://mistral.ai/news/shieldstral/
