## 按产品线出块

### Codex

本期 Codex 入选 2 条高置信线索，主线集中在 Computer History 与 Linux 桌面预览及代理导入功能。

#### Codex 推出 Computer History 功能，记录跨应用活动

- Codex 在 ChatGPT 桌面应用（macOS）中推出可选的 Computer History 功能。
- 该功能可将用户在应用和网站上的活动转化为记忆和时间线，供 ChatGPT 和 Codex 使用。
- 用户需主动开启，属于隐私可控的个性化功能。
- 结论：Computer History 是 Codex 在个性化与上下文理解上的重要尝试，但需平衡隐私与便利。
- 影响：该功能有望提升 Codex 在复杂任务中的上下文感知能力，但可能引发隐私讨论，影响用户采用。
- 原文：https://developers.openai.com/codex/changelog/#computer-history

#### Codex 推出 Linux 桌面预览版及代理导入功能

- ChatGPT 桌面应用现已提供 Linux 预览版，支持 Ubuntu、Debian 和 Fedora 等发行版，涵盖 x64 和 ARM64 架构。
- 同时新增代理导入功能，方便用户迁移配置。
- 这标志着 Codex 在跨平台支持上的扩展。
- 结论：Linux 桌面预览版的推出是 Codex 扩大用户基础的重要一步，尤其对开发者社区。
- 影响：Linux 开发者将能更便捷地使用 Codex，可能提升其在技术人群中的渗透率。
- 原文：https://developers.openai.com/codex/changelog/#linux-desktop-preview-and-agent-imports

### Claude

本期 Claude 入选 1 条高置信线索，重点在于文本水印技术的工作原理说明。

#### Claude 公布文本水印技术原理，未来模型将内置水印

- Anthropic 于近期发布公告，解释 Claude 文本水印的工作原理。
- 未来 Claude 模型生成的文本将包含水印，用于判断文本是否由 Claude 生成。
- Anthropic 表示正与其他主要人工智能提供商合作实施类似机制。
- 结论：文本水印是人工智能内容溯源的重要举措，Claude 率先公开技术细节，显示其合规与透明度承诺。
- 影响：该技术有助于打击虚假信息，但可能影响生成文本的多样性，需平衡可用性与可追溯性。
- 原文：https://www.anthropic.com/news/claude-text-watermark

### DeepSeek

本期 DeepSeek 入选 1 条高置信线索，重点在于 DeepSeek-V4-Pro 的正式发布。

#### DeepSeek-V4-Pro 正式发布，API 调用方式不变

- DeepSeek 于近期在 APP、Web 和 API 端全面推出 DeepSeek-V4-Pro 的正式版本。
- API 调用方式保持不变，开发者只需将模型名称设置为 deepseek-v4-pro 即可使用。
- 此前 DeepSeek-V4-Flash 已进入公开测试阶段，本次 V4-Pro 的发布标志着 V4 系列模型走向成熟。
- 结论：DeepSeek-V4-Pro 的正式发布是模型能力的重要升级，且保持了 API 兼容性，降低了迁移成本。
- 影响：对开发者而言，可以无缝升级到更强模型，提升应用性能；对行业而言，DeepSeek 在开源与闭源之间的竞争地位进一步巩固。
- 原文：https://api-docs.deepseek.com/updates#deepseek-v4-pro-update

### Mistral

本期 Mistral 入选 1 条高置信线索，重点在于欧洲主权人工智能基础设施与开放模型战略。

#### Mistral 发布欧洲主权人工智能基础设施计划

- Mistral 于近期宣布整合区域推理基础设施、开放模型和长期承诺，以支持欧洲主权人工智能。
- 该计划旨在让欧洲掌控自身人工智能未来，并为全球提供路线图。
- 具体包括新的计算基础设施和开放模型发布。
- 结论：Mistral 的战略聚焦于欧洲数据主权与自主可控，是地缘政治背景下人工智能竞争的重要布局。
- 影响：该计划可能吸引欧洲政府与企业客户，增强 Mistral 在欧洲市场的竞争力，并推动区域人工智能生态发展。
- 原文：https://mistral.ai/news/regional-inference-open-models-new-compute/
