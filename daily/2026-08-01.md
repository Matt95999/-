## 按产品线出块

### Codex

本期 Codex 入选 3 条高置信线索，主线集中在 GPT-5.4 系列从 Codex 退役、浏览器升级与多仓库审查、以及 CLI 0.146.0 的发布。

#### GPT-5.4 系列将于 8 月 31 日从 Codex 中退役

- OpenAI 宣布，自 2026 年 8 月 31 日起，GPT-5.4 和 GPT-5.4 mini 将不再在 Codex 中供使用 ChatGPT 登录的用户使用。
- 这两个模型仍将在 OpenAI API 上继续可用，但 Codex 用户需要迁移到其他模型。
- 这一变化可能促使 Codex 用户转向更新的模型，如 GPT-5.6 系列。
- 结论：这是 Codex 产品线的一次模型迭代，旨在推动用户采用更新模型。
- 影响：开发者需要调整 Codex 中的模型选择，可能影响依赖 GPT-5.4 的自动化工作流。
- 原文：https://developers.openai.com/codex/changelog/#gpt-5-4-and-gpt-5-4-mini-retire-from-codex-on-august-31

#### Codex 更新：浏览器升级、多仓库审查和图像编辑

- 最新 ChatGPT 桌面应用更新使浏览、代码审查和生成图像编辑更快更易用。
- 内置浏览器提供更快的上下文查找，支持多仓库代码审查，并增强了图像编辑功能。
- 这些功能旨在提升开发者在 Codex 中的整体效率。
- 结论：这是 Codex 产品体验的持续优化，强化其作为开发助手的实用性。
- 影响：开发者可以更高效地处理多仓库项目，并直接在 Codex 中编辑生成图像。
- 原文：https://developers.openai.com/codex/changelog/#browser-upgrades-multi-repository-review-and-image-editing-26-727

#### Codex CLI 0.146.0 发布

- Codex CLI 0.146.0 通过 npm 发布，新增功能包括使用 /new 或 /clear 命名新会话、固定重要线程等。
- 此前版本 0.145.0 引入了实验性分页线程历史，0.144.6 刷新了 GPT-5.6 系列的捆绑指令。
- 这些更新持续改进命令行工具的用户体验和稳定性。
- 结论：Codex CLI 的迭代保持高频，注重开发者工作流细节。
- 影响：命令行用户可获得更流畅的会话管理和线程处理能力。
- 原文：https://developers.openai.com/codex/changelog/#codex-cli-0-146-0 | https://developers.openai.com/codex/changelog/#codex-cli-0-145-0 | https://developers.openai.com/codex/changelog/#codex-cli-0-144-6

### Claude

本期 Claude 入选 1 条高置信线索，重点在于 Anthropic 与 Cognizant 扩大合作，将 Claude 带给企业客户。

#### Anthropic 与 Cognizant 扩大合作，推动 Claude 企业级应用

- Anthropic 宣布与 Cognizant 扩大合作伙伴关系，将 Claude 嵌入 Cognizant 的多个平台。
- Cognizant 已培训超过 3 万名员工使用 Claude，并成为 Claude 合作伙伴网络中的全球首要合作伙伴。
- 此举旨在加速 Claude 在企业客户中的采用。
- 结论：这是 Claude 在企业市场的重要拓展，通过系统集成商扩大影响力。
- 影响：企业客户可通过 Cognizant 的服务更便捷地部署 Claude，提升人工智能应用效率。
- 原文：https://www.anthropic.com/news/cognizant-anthropic

### DeepSeek

本期 DeepSeek 入选 1 条高置信线索，重点在于 DeepSeek-V4-Flash 更新。

#### DeepSeek-V4-Flash 更新：API 公开测试版发布

- DeepSeek 官方发布 DeepSeek-V4-Flash API 公开测试版。
- API 调用方式保持不变，只需将模型名称设置为 deepseek-v4-flash 即可使用最新模型。
- 该更新旨在提供更快的模型响应，可能面向实时应用场景。
- 结论：DeepSeek 通过轻量级模型扩展产品线，满足不同性能需求。
- 影响：开发者可以低成本接入新模型，用于需要快速响应的应用。
- 原文：https://api-docs.deepseek.com/updates#deepseek-v4-flash-update
