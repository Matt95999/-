## 按产品线出块

### Codex

本期 Codex 入选 2 条高置信线索，主线集中在 GPT-5.4 系列模型将于 8 月 31 日从 Codex 界面退役，以及桌面应用更新带来的浏览器、多仓库审查和图像编辑功能增强。

#### GPT-5.4 系列模型将于 8 月 31 日从 Codex 界面退役

- 事实：OpenAI 宣布，自 2026 年 8 月 31 日起，GPT-5.4 和 GPT-5.4 mini 将不再在 Codex 界面中提供给使用 ChatGPT 登录的用户。
- 这些模型仍可通过 OpenAI API 使用，但 Codex 产品内的模型选择将发生变化。
- 该消息来自 Codex 开发者更新日志，发布日期为 2026 年 7 月 31 日。
- 结论：这是 Codex 产品的一次模型阵容调整，旨在引导用户迁移到更新的模型。
- 影响：依赖 Codex 界面使用 GPT-5.4 系列的开发者需要在截止日期前调整工作流，转向 API 或新模型。
- 原文：https://developers.openai.com/codex/changelog/#gpt-5-4-and-gpt-5-4-mini-retire-from-codex-on-august-31

#### Codex 桌面应用更新：浏览器、多仓库审查与图像编辑增强

- 事实：Codex 桌面应用发布了版本 26.727，更新内容包括内置浏览器浏览速度提升、多仓库代码审查支持以及图像编辑功能增强。
- 用户现在可以在浏览器中更快地查找上下文，并更高效地审查多个仓库的代码。
- 该更新发布于 2026 年 7 月 30 日，来自 Codex 开发者更新日志。
- 结论：这是一次功能增强型更新，旨在提升开发者在 Codex 中的日常操作效率。
- 影响：开发者可以更流畅地进行多项目协作和图像相关任务，减少上下文切换成本。
- 原文：https://developers.openai.com/codex/changelog/#browser-upgrades-multi-repository-review-and-image-editing-26-727

### DeepSeek

本期 DeepSeek 入选 1 条高置信线索，重点在于 DeepSeek-V4-Flash API 正式进入公开测试阶段，调用方式保持不变。

#### DeepSeek-V4-Flash API 进入公开测试

- 事实：DeepSeek 官方宣布 DeepSeek-V4-Flash API 正式进入公开测试阶段。
- 调用方式保持不变，开发者只需将模型名称设置为 deepseek-v4-flash 即可使用最新模型。
- 该消息来自 DeepSeek API 更新文档，发布日期为 2026 年 7 月 31 日。
- 结论：DeepSeek-V4-Flash 的公开测试标志着 DeepSeek 在轻量级模型上的快速迭代。
- 影响：开发者可以立即通过 API 体验新模型，但需注意测试阶段的稳定性可能有限。
- 原文：https://api-docs.deepseek.com/updates#deepseek-v4-flash-update
