### Codex

本期 Codex 入选 1 条高置信线索，重点在于 Codex CLI 0.144.6。

#### Codex CLI 0.144.6 更新 GPT-5.6 系列模型指令

- 事实：OpenAI 于 2026 年 7 月 18 日发布 Codex CLI 0.144.6，主要更新了针对 GPT-5.6 Sol、Terra 和 Luna 等模型的捆绑指令。
- 事实：此前版本 0.144.5 改进了危险命令检测，包括对强制 rm 等操作的识别。
- 结论：本次更新属于常规模型适配，表明 Codex 正在持续跟进 OpenAI 最新模型能力。
- 影响：开发者使用 Codex CLI 时能获得对 GPT-5.6 系列更准确的指令支持，提升编码助手的安全性和效率。
- 原文：https://developers.openai.com/codex/changelog/#codex-cli-0-144-6

### Claude Code

本期 Claude Code 入选 1 条高置信线索，重点在于 Claude Code 2.1.216。

#### Claude Code 2.1.216 新增沙箱文件系统禁用设置

- 事实：Anthropic 于 2026 年 7 月 20 日发布 Claude Code 2.1.216，新增 sandbox.filesystem.disabled 设置，允许在保持网络出口控制的同时跳过文件系统隔离。
- 事实：该版本还修复了长会话中消息归一化导致的性能下降问题。
- 结论：本次更新增强了 Claude Code 的安全灵活性，并优化了长时间使用体验。
- 影响：用户可根据需求灵活配置沙箱策略，同时长会话性能提升有助于持续编码工作流。
- 原文：https://code.claude.com/docs/en/changelog#2-1-216
