## 按产品线出块

### Codex

本期 Codex 入选 2 条高置信线索，主线集中在 Codex CLI 0.144.3 版本发布以及 Codex 正式集成至 ChatGPT 桌面应用。

#### Codex CLI 0.144.3 发布，为版本号更新

- 事实：OpenAI 于 2026 年 7 月 13 日发布 Codex CLI 0.144.3 版本，该版本仅为版本号更新，未合并任何拉取请求变更。
- 同日发布的 0.144.2 版本恢复了 Guardian 自动审查策略和请求格式，并修复了相关 bug；0.144.1 版本修复了 GitHub 返回压缩或精简响应时独立安装失败的问题。
- 结论：Codex CLI 近期以修复为主，版本号更新表明维护持续但创新放缓。
- 影响：稳定性提升但功能创新不足，可能影响开发者选择。
- 原文：https://developers.openai.com/codex/changelog/#codex-cli-0-144-3

#### Codex 正式集成至 ChatGPT 桌面应用

- 事实：OpenAI 于 2026 年 7 月 9 日宣布，Codex 现已集成至 macOS 和 Windows 版 ChatGPT 桌面应用。现有 Codex 应用用户可正常更新，保留项目、设置和工作流。
- 用户可在 ChatGPT 桌面应用中直接使用 Codex 功能，无需单独启动 Codex 应用。
- 结论：Codex 整合进 ChatGPT 桌面端，强化了 OpenAI 产品生态协同。
- 影响：提升用户便利性，增强生态壁垒，对独立 CLI 工具形成竞争。
- 原文：https://developers.openai.com/codex/changelog/#codex-joins-the-chatgpt-desktop-app

### Claude

本期 Claude 入选 2 条高置信线索，主线集中在 UST 将 Claude 引入物理人工智能的案例研究，以及 Anthropic 推出 Claude 使用反思功能。

#### UST 将 Claude 引入物理人工智能领域

- 事实：Anthropic 于 2026 年 7 月 9 日发布案例研究，介绍 UST 公司如何将 Claude 应用于物理人工智能场景。
- 该案例展示了 Claude 在机器人、自动化等物理世界任务中的潜力，但具体技术细节和效果未详细披露。
- 结论：Claude 进入物理人工智能领域，拓展了模型的应用边界。
- 影响：推动大模型在机器人等物理场景的落地，与 Mistral 等竞品展开竞争。
- 原文：https://www.anthropic.com/news/ust-claude

#### Anthropic 推出 Claude 使用反思功能

- 事实：Anthropic 于 2026 年 7 月 9 日宣布推出新功能，允许用户追踪和可视化 Claude 的使用情况，并评估使用时间是否符合个人目标。
- 该功能旨在帮助用户更高效、更有意识地使用 Claude，提升用户自我管理能力。
- 结论：Claude 的反思功能帮助用户优化使用习惯，提升产品价值。
- 影响：增强用户粘性，推动人工智能产品向用户赋能方向发展。
- 原文：https://www.anthropic.com/news/reflect-with-claude

### Claude Code

本期 Claude Code 入选 1 条高置信线索，重点在于 Claude Code 2.1.208 版本更新，新增屏幕阅读器模式等无障碍功能。

#### Claude Code 2.1.208 发布，新增屏幕阅读器模式

- 事实：Anthropic 于 2026 年 7 月 14 日发布 Claude Code 2.1.208 版本，新增屏幕阅读器模式，用户可通过命令行参数、环境变量或配置文件启用纯文本渲染，以支持无障碍访问。
- 此前版本 2.1.207 已在 Bedrock、Vertex 人工智能和 Foundry 上默认启用自动模式，并修复了终端冻结问题；2.1.206 版本新增了目录路径建议和 /doctor 检查功能。
- 结论：Claude Code 通过版本迭代持续增强功能，无障碍模式是其差异化竞争的重要举措。
- 影响：提升开发者体验，扩大用户基础，对 Codex 等竞品形成压力。
- 原文：https://code.claude.com/docs/en/changelog#2-1-208

### Mistral

本期 Mistral 入选 2 条高置信线索，主线集中在 Robostral Navigate 模型的发布，以及 Studio 产品为人工智能提示词和技能提供版本化管理系统。

#### Mistral 发布 Robostral Navigate 模型，专为具身导航设计

- 事实：Mistral 人工智能于 2026 年 7 月 8 日发布 Robostral Navigate，这是其首个专为具身导航构建的模型，参数量为 8B，在 R2R-CE 基准上达到 76.6% 的准确率。
- 该模型仅需单个 RGB 摄像头即可工作，无需深度传感器、激光雷达或多摄像头，降低了硬件成本。
- 结论：Mistral 发布 Robostral Navigate，以低成本方案切入具身导航市场。
- 影响：降低机器人导航硬件成本，推动具身人工智能普及，与 Claude 形成竞争。
- 原文：https://mistral.ai/news/robostral-navigate/
