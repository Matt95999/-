### Claude Code

本期 Claude Code 入选 1 条高置信线索，重点在于 Claude Code 2.1.202 版本发布。

#### Claude Code 2.1.202 发布，新增动态工作流大小设置

- 事实：Claude Code 于 2026 年 7 月 6 日发布 2.1.202 版本，新增“动态工作流大小”设置，用户可通过 /config 命令控制 Claude 生成动态工作流时使用的代理数量（小/中/大），该设置为建议性指导。
- 同期还发布了 2.1.201 和 2.1.200 版本，其中 2.1.201 优化了 Claude Sonnet 5 会话中的系统角色提示，2.1.200 更改了 AskUserQuestion 对话框的默认行为，不再自动继续，并允许通过 /config 设置空闲超时。
- 结论：Claude Code 持续优化开发者体验，通过细粒度控制提升用户对工作流规模的掌控。
- 影响：开发者可更灵活地调整代理数量以适应不同复杂度的任务，提升编码效率。
- 原文：https://code.claude.com/docs/en/changelog#2-1-202
