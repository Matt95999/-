## 按产品线出块

### Codex

本期 Codex 入选 2 条高置信线索，主线集中在 Codex CLI 0.146.1 发布与 GPT-5.4 系列在 Codex 中退役预告。

#### Codex CLI 0.146.1 发布：针对网络能力模型的自动审查默认值更安全

- OpenAI 于 2026 年 8 月 5 日发布 Codex CLI 0.146.1，用户可通过 npm 安装。
- 该版本主要修复了针对具备网络能力模型的自动审查默认值，使其更安全。
- 此前 0.146.0 版本已引入会话命名和线程固定功能，0.145.0 则增加了分页线程历史。
- 结论：这是一次常规的开发者工具迭代，重点在于安全性的微调。
- 影响：对使用 Codex CLI 的开发者而言，自动审查默认值的调整可能影响代码审查流程，但整体影响有限。
- 原文：https://developers.openai.com/codex/changelog/#codex-cli-0-146-1

#### GPT-5.4 系列将于 8 月 31 日从 Codex 中退役

- OpenAI 宣布自 2026 年 8 月 31 日起，GPT-5.4 和 GPT-5.4 mini 将不再在 Codex 中供 ChatGPT 登录用户使用。
- 这两个模型仍将在 OpenAI API 上继续提供。
- 该公告发布于 2026 年 7 月 31 日。
- 结论：这是模型生命周期管理的常规操作，旨在引导用户迁移至更新模型。
- 影响：依赖 Codex 中 GPT-5.4 系列的用户需在截止日期前调整工作流，否则可能影响开发效率。
- 原文：https://developers.openai.com/codex/changelog/#gpt-5-4-and-gpt-5-4-mini-retire-from-codex-on-august-31

### DeepSeek

本期 DeepSeek 入选 1 条高置信线索，重点在于 DeepSeek-V4-Flash API 公开测试版更新。

#### DeepSeek-V4-Flash API 进入公开测试阶段

- DeepSeek 于 2026 年 7 月 31 日宣布 DeepSeek-V4-Flash API 正式进入公开测试。
- 调用方式保持不变，只需将模型名称设置为 deepseek-v4-flash 即可使用最新版本。
- 该更新发布在 DeepSeek API 文档的更新日志中。
- 结论：这是 DeepSeek 模型产品化的重要一步，表明其正在加速推出新模型。
- 影响：开发者可以立即试用新模型，可能带来性能提升，但需注意测试阶段的稳定性。
- 原文：https://api-docs.deepseek.com/updates#deepseek-v4-flash-update

### Mistral

本期 Mistral 入选 1 条高置信线索，重点在于发布 Shieldstral 安全分类器。

#### Mistral 发布 Shieldstral：3B 开源多模态安全分类器

- Mistral 于 2026 年 8 月 4 日发布 Shieldstral，一个 3B 参数的开源多模态安全分类器。
- 据称其性能优于体积高达 7 倍的模型。
- 该消息发布在 Mistral 官方新闻页面。
- 结论：这是 Mistral 在安全领域的一次重要产品发布，强调开源和高效。
- 影响：Shieldstral 可能为开发者提供更轻量、高效的安全过滤方案，对人工智能内容安全领域有积极影响。
- 原文：https://mistral.ai/news/shieldstral/
