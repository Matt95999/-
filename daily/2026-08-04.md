## 按产品线出块

### Codex

本期 Codex 入选 3 条高置信线索，主线集中在 GPT-5.4 系列模型退役、桌面应用功能升级以及 CLI 工具迭代。

#### GPT-5.4 系列模型将于 8 月 31 日从 Codex 中退役

- OpenAI 宣布，自 2026 年 8 月 31 日起，GPT-5.4 和 GPT-5.4 mini 将不再在 Codex 产品中供 ChatGPT 登录用户使用。
- 不过，这两个模型仍可通过 OpenAI API 继续访问，开发者可继续在 API 层面调用。
- 该变更旨在引导 Codex 用户迁移至更新的模型版本，并简化产品线。
- 结论：这是一次产品生命周期管理动作，旨在推动用户向新模型迁移。
- 影响：Codex 用户需在截止日期前调整工作流，避免因模型退役导致功能中断。
- 原文：https://developers.openai.com/codex/changelog/#gpt-5-4-and-gpt-5-4-mini-retire-from-codex-on-august-31

#### Codex 桌面应用更新：浏览器升级、多仓库审查与图像编辑

- 最新版 ChatGPT 桌面应用（版本 26.727）增强了内置浏览器的上下文查找能力，使浏览和查找信息更快速。
- 同时新增多仓库代码审查功能，支持跨仓库的代码检查，并改进了图像编辑体验。
- 这些更新旨在提升开发者在 Codex 中的整体工作效率。
- 结论：这是一次面向开发者体验的功能增强，强化了 Codex 作为一体化开发助手的定位。
- 影响：开发者可更高效地处理多仓库项目，并直接在桌面应用中完成更多任务。
- 原文：https://developers.openai.com/codex/changelog/#browser-upgrades-multi-repository-review-and-image-editing-26-727

#### Codex CLI 0.146.0 发布：会话命名与线程固定等新功能

- Codex CLI 0.146.0 版本新增了会话命名功能，用户可通过 /new 或 /clear 命令为会话命名，并支持固定重要线程。
- 此前版本还引入了实验性的分页线程历史功能，以及针对 GPT-5.6 Sol、Terra 和 Luna 的指令更新。
- 这些迭代持续优化命令行工具的用户体验和性能。
- 结论：CLI 工具的持续迭代表明 OpenAI 重视开发者工作流中的细节体验。
- 影响：命令行用户可更有序地管理会话，提升长期项目的可维护性。
- 原文：https://developers.openai.com/codex/changelog/#codex-cli-0-146-0 | https://developers.openai.com/codex/changelog/#codex-cli-0-145-0 | https://developers.openai.com/codex/changelog/#codex-cli-0-144-6

### DeepSeek

本期 DeepSeek 入选 1 条高置信线索，重点在于 DeepSeek-V4-Flash API 公开测试版的正式发布。

#### DeepSeek-V4-Flash API 公开测试版正式发布

- DeepSeek 官方宣布 DeepSeek-V4-Flash API 现已进入公开测试阶段。
- API 调用方式保持不变，开发者只需将模型名称设置为 deepseek-v4-flash 即可使用最新模型。
- 该更新在 DeepSeek API 文档中发布，标志着模型向更广泛用户开放。
- 结论：这是 DeepSeek 模型产品化的重要一步，通过公开测试版吸引开发者试用。
- 影响：开发者可立即接入新模型，推动 DeepSeek 生态的扩展。
- 原文：https://api-docs.deepseek.com/updates#deepseek-v4-flash-update
