## 按产品线出块

### Codex

本期 Codex 入选 2 条高置信线索，主线集中在桌面应用更新（26.727）与 CLI 0.146.0，分别强化浏览器内上下文获取、多仓库代码审查、图像编辑，以及会话命名、线程固定等新功能。

#### Codex 桌面应用更新 26.727：浏览器升级、多仓库审查与图像编辑

- OpenAI 于 7 月 30 日发布 Codex 桌面应用更新（版本 26.727），主要改进包括内置浏览器中更快地浏览和查找上下文、多仓库代码审查，以及更便捷的图像编辑功能。
- 该更新旨在提升开发者在浏览、代码审查和图像处理任务中的效率，减少上下文切换成本。
- 结论：这是 Codex 产品功能的一次实质性增强，表明 OpenAI 正在加速完善其人工智能编程助手的端到端体验。
- 影响：对开发者而言，多仓库审查和浏览器集成将显著提升复杂项目的处理效率，可能吸引更多团队采用 Codex。
- 原文：https://developers.openai.com/codex/changelog/#browser-upgrades-multi-repository-review-and-image-editing-26-727

#### Codex CLI 0.146.0：新增会话命名与线程固定功能

- OpenAI 于 7 月 29 日发布 Codex CLI 0.146.0，可通过 npm 安装，新增功能包括使用 /new 或 /clear 命名新会话，以及固定重要线程。
- 该版本延续了近期 CLI 的快速迭代节奏，此前 0.145.0 引入了实验性分页线程历史，0.144.6 更新了 GPT-5.6 Sol、Terra 和 Luna 的捆绑指令。
- 结论：CLI 的持续更新表明 OpenAI 正积极优化命令行工作流，提升会话管理和上下文恢复能力。
- 影响：对于重度使用 CLI 的开发者，会话命名和线程固定将改善多任务管理，提高日常开发效率。
- 原文：https://developers.openai.com/codex/changelog/#codex-cli-0-146-0 | https://developers.openai.com/codex/changelog/#codex-cli-0-145-0 | https://developers.openai.com/codex/changelog/#codex-cli-0-144-6

### Claude

本期 Claude 入选 1 条高置信线索，重点在于与 Cognizant 扩大合作伙伴关系，将 Claude 嵌入其平台，培训超 3 万名员工，并成为全球首要合作伙伴。

#### Anthropic 与 Cognizant 扩大合作，推动 Claude 企业级应用

- Anthropic 于 7 月 27 日宣布与 Cognizant 扩大合作伙伴关系，Cognizant 将 Claude 嵌入其多个平台，并已培训超过 3 万名员工。
- Cognizant 同时成为 Claude 合作伙伴网络中的全球首要合作伙伴，标志着双方在企业级人工智能服务领域的深度绑定。
- 结论：这是 Claude 在企业市场的重要拓展，通过系统集成商扩大其生态覆盖。
- 影响：企业客户将更容易通过 Cognizant 获得 Claude 驱动的解决方案，可能加速 Claude 在金融、医疗等行业的渗透。
- 原文：https://www.anthropic.com/news/cognizant-anthropic
