本期 Codex 入选 1 条高置信线索，重点在于 Codex CLI 0.147.0。

#### Codex 发布新一轮更新

- 事实：OpenAI 于近期发布 Codex CLI 0.147.0 版本，可通过 npm 命令 `npm install -g @openai/codex@0.147.0` 安装。该版本新增功能包括安装便携式 智能体 插件，并支持在本地、角色等范围内进行搜索。
- 事实：此前版本 0.146.1 于 2026-08-05 发布，主要修复了针对网络能力模型的自动审查默认值，使其更安全；0.146.0 于 2026-07-29 发布，新增会话命名（通过 /new 或 /clear）和线程固定功能。
- 事实：这些更新均记录在 OpenAI 官方 Codex 开发者更新日志中，表明 Codex CLI 正在快速迭代，持续增强开发者体验。
- 结论：该消息应视为 Codex 产品线的常规版本迭代，但新增的插件安装与搜索功能标志着其生态扩展的重要一步。
- 影响：对开发者而言，Codex CLI 的可扩展性和安全性提升将优化编码自动化流程，并可能吸引更多用户采用。
