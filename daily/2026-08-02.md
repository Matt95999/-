## 按产品线出块

### Codex

本期 Codex 入选 2 条高置信线索，主线集中在 GPT-5.4 系列从 Codex 产品线退役，以及桌面应用新增浏览器、多仓库审查和图像编辑功能。

#### GPT-5.4 系列将从 Codex 产品线退役

- 事实：OpenAI 宣布，自 2026 年 8 月 31 日起，GPT-5.4 和 GPT-5.4 mini 将不再在 Codex 中供使用 ChatGPT 登录的用户使用。不过，这两个模型仍可通过 OpenAI API 继续访问。
- 该变更旨在引导 Codex 用户迁移至更新的模型，同时保持 API 层面的模型可用性。
- 结论：这是 OpenAI 对 Codex 产品线进行模型代际更新的常规操作，属于产品生命周期管理。
- 影响：对依赖 Codex 内置模型的开发者而言，需在截止日期前调整工作流，转向 API 或新模型，可能带来短期迁移成本。
- 原文：https://developers.openai.com/codex/changelog/#gpt-5-4-and-gpt-5-4-mini-retire-from-codex-on-august-31

#### ChatGPT 桌面应用更新：浏览器、多仓库审查与图像编辑

- 事实：OpenAI 发布了 ChatGPT 桌面应用的最新更新，版本号为 26.727，主要改进包括内置浏览器、多仓库代码审查和图像编辑功能。
- 这些功能旨在提升用户在浏览、代码审查和图像处理方面的效率。
- 结论：这是 ChatGPT 桌面应用的常规功能迭代，旨在增强用户体验和生产力。
- 影响：对于使用 Codex 或 ChatGPT 进行开发工作的用户，新功能可减少上下文切换，提高工作流效率。
- 原文：https://developers.openai.com/codex/changelog/#browser-upgrades-multi-repository-review-and-image-editing-26-727

### Claude

本期 Claude 入选 1 条高置信线索，重点在于 Anthropic 与 Cognizant 扩大合作，将 Claude 引入企业客户，并培训超过 3 万名员工。

#### Anthropic 与 Cognizant 扩大合作，推动 Claude 企业级应用

- 事实：Anthropic 宣布与 Cognizant 扩大合作伙伴关系，将 Claude 嵌入 Cognizant 的多个平台，并已培训超过 3 万名员工。
- Cognizant 还成为 Claude 合作伙伴网络中的全球首要合作伙伴。
- 结论：这是 Anthropic 在企业市场的重要布局，通过系统集成商扩大 Claude 的触达范围。
- 影响：企业客户可通过 Cognizant 的服务更便捷地采用 Claude，加速人工智能在行业中的落地。
- 原文：https://www.anthropic.com/news/cognizant-anthropic

### DeepSeek

本期 DeepSeek 入选 1 条高置信线索，重点在于 DeepSeek-V4-Flash API 进入公开测试阶段，调用方式不变。

#### DeepSeek-V4-Flash API 进入公开测试

- 事实：DeepSeek 官方宣布 DeepSeek-V4-Flash API 现已进入公开测试阶段，调用方式保持不变，只需将模型名称设置为 deepseek-v4-flash 即可使用。
- 该更新发布在 DeepSeek API 更新日志中。
- 结论：这是 DeepSeek 模型产品化的新进展，表明其正在快速迭代模型版本。
- 影响：开发者可以立即尝试新模型，但需注意测试阶段的稳定性，可能影响生产环境的选择。
- 原文：https://api-docs.deepseek.com/updates#deepseek-v4-flash-update
